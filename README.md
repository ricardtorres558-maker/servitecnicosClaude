# Servitecnicos

Página web de Servitecnicos: impresoras, tóners, tintas y repuestos con envíos en Bogotá.

- `index.html`: la página completa (intro con el logo, categorías en video y catálogo).
- `media/`: videos de las categorías y logos de las marcas.

Se publica automáticamente con Vercel cada vez que cambia este repositorio.
